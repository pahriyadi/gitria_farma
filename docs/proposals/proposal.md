## 1. LATAR BELAKANG & TUJUAN
Dalam rangka meningkatkan mutu pelayanan medis, kecepatan administrasi pasien, akurasi pengelolaan persediaan obat farmasi, efisiensi resto gizi pasien, serta transparansi pembukuan keuangan berstandar akuntansi resmi, dibutuhkan satu sistem terpadu (**All-in-One Enterprise ERP**) yang menggabungkan seluruh unit operasional ke dalam satu basis data terpusat (*single source of truth*).

Sistem ini dirancang khusus untuk memangkas waktu tunggu antrean pasien, mencegah kebocoran stok obat & bahan baku, mengotomatisasi jurnal keuangan tanpa kesalahan manual, serta menyajikan laporan laba rugi dan neraca keuangan secara *real-time*.

## 5. SKEMA & TAHAPAN PEMBAYARAN (*PAYMENT TERMS*)

Pembayaran nilai investasi Rp 20.000.000,- dapat dilakukan secara bertahap melalui 3 termin:

```
┌─────────────────────────┐     ┌─────────────────────────┐     ┌─────────────────────────┐
│     TERMIN 1 (DP)       │     │     TERMIN 2 (UAT)      │     │    TERMIN 3 (FINAL)     │
│          40%            │────►│          40%            │────►│          20%            │
│     Rp 8.000.000,-      │     │     Rp 8.000.000,-      │     │     Rp 4.000.000,-      │
│  Penandatanganan Mou &  │     │  Sistem Selesai Deploy, │     │  Pelatihan Staf (BAST)  │
│  Setup Server & Domain  │     │  Uji Coba & Integrasi   │     │   & Serah Terima Penuh  │
└─────────────────────────┘     └─────────────────────────┘     └─────────────────────────┘
```

1. **Termin 1 (Uang Muka / DP 40% - Rp 8.000.000,-)**: Dibayarkan saat penandatanganan kesepakatan kerjasama, inisialisasi server, aktivasi domain, dan penyusunan master data awal.
2. **Termin 2 (Implementasi & UAT 40% - Rp 8.000.000,-)**: Dibayarkan setelah seluruh modul selesai diuji coba (*User Acceptance Test*) oleh perwakilan unit kerja klinik.
3. **Termin 3 (Pelunasan & Serah Terima 20% - Rp 4.000.000,-)**: Dibayarkan setelah pelatihan staf/nakes selesai dan penandatanganan Berita Acara Serah Terima (BAST).
